Fibonacci Sequence in Python

Description

This repository contains a Python program that generates the Fibonacci sequence for the number of terms entered by the user.

The program starts with 0 and 1. It uses a loop to print each term and calculate the next term by adding the previous two terms.

How to Run

1. Make sure Python is installed on your computer.
2. Download the fibonacci.py file.
3. Run the file using Python.
4. Enter the number of terms when prompted.

Example Output

For an input of 7:

Enter the number of terms: 7
0 1 1 2 3 5 8

Learning Objective

To understand variables, loops, user input, and the generation of the Fibonacci sequence in Python.
